# Slime Rancher 2 Interactive Map (enhanced)

Fork of [BrookJeynes/slime-rancher-2-interactive-map](https://github.com/BrookJeynes/slime-rancher-2-interactive-map).

## Changes
- Added screenshots for Gordo points, sourced from [Map Genie](https://mapgenie.io/slime-rancher-2).
- Screenshots are shown in the popup when you click a Gordo marker.

## Original features
See the upstream README for the full list of features (Gordo locations, map nodes, treasure pods, research drones, etc.).

## Running locally
```bash
pnpm install
pnpm run dev
```

All game assets belong to Monomi Park. This is a fan project.
